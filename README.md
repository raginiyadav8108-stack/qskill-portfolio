# QSkill Internship - Full Stack Development Tasks

This repository contains the completed tasks for the QSkill Internship (Domain: Full Stack Development) for the batch starting 14th September 2026.

## 🛠️ Tasks Completed (Slab 1 - Beginners)

### 1. Personal Portfolio Website (Task 1)
- **Features:** Fully responsive developer profile, interactive skills section, project showcase, and validated contact form.
- **Tech Stack:** HTML5, CSS3, JavaScript.

### 2. Online To-Do & Task Management Application (Task 2)
- **Features:** Full-stack task manager with complete CRUD functionality (Create, Read, Update, Delete), task completion toggle, and form validation.
- **Tech Stack:** React.js, Tailwind CSS, Node.js, Express.js.

### 3. Blog Management Website (Task 3)
- **Features:** Content management workflow with a responsive homepage, detailed post view, and dedicated interfaces for creating/editing posts.
- **Tech Stack:** React.js, Node.js, Express.js.
